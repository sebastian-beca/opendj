# Proposal

Planned for: **v1.0 · Ready for any DJ switching over**

## Why

Slip should apply to hot cues, loops, rolls, reverse, censor, scratching and pads alike, with the hidden playhead shown, so any trick returns in time.

## What Changes

- Slip applies to every jump and pad action, not only loops and rolls.
- A ghost playhead on the waveforms while slipping.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `deck-transport`: slip for every action, ghost playhead

## Out of Scope

None.

## Impact

engine deck slip, waveform shader.
