# Proposal

Planned for: **v0.6 · Buy it from the artist**

## Why

Bandcamp is the main artist-direct store. What a DJ has bought there should arrive in the library in lossless quality without manual downloads.

## What Changes

- Sign in to Bandcamp from an add-on settings page.
- List the DJ's purchases, download new ones as FLAC into the purchase inbox, analysed and tagged.

## Capabilities

### New Capabilities

- `bandcamp-sync`: sync a DJ's Bandcamp purchases into the library

### Modified Capabilities

None.

## Out of Scope

- Buying inside openDJ.

## Impact

New add-on (outside or inside the repo, per licence), plugin source API.
