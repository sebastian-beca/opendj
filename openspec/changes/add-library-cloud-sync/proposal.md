# Proposal

Planned for: **v1.x · after 1.0**

## Why

DJs with two machines want the same library, cues and lists on both.

## What Changes

- Sync the library database (not audio) between machines through a folder the DJ picks, such as iCloud Drive.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `music-library`: sync library metadata between machines

## Out of Scope

- Syncing audio files.

## Impact

library change log.
