# Proposal

Planned for: **v1.0 · Ready for any DJ switching over**

## Why

The library is where DJs live. After stages, health, duplicates and clean-up, the remaining pieces are fingerprint duplicates, search across every source, faster navigation, and getting lists out.

## What Changes

- Duplicates found by audio fingerprint, not just names, on import too.
- Search across Collection, Files and store add-ons in one box.
- Jump to artist, album or label; Show in playlists; group by any field.
- Waveform thumbnails in rows; load to any of 4 decks by key; Load next from Automix.
- Export lists to M3U.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `library-search`: one search across sources; grouping and jumps
- `library-health`: fingerprint duplicates
- `music-library`: M3U export
- `track-browser`: row waveforms and load by key

## Out of Scope

- Cloud library sync (after 1.0).

## Impact

library, app browser, add-on store search.
