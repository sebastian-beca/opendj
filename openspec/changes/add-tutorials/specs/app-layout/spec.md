## ADDED Requirements

### Requirement: Tutorials
Help › Tutorials SHALL list hands-on tutorials for Clean Collection, Looping, Using FX, Filtering tracks and Automix; each SHALL highlight the real controls step by step, be closable at any step, and be marked done once finished.

#### Scenario: Learn looping
- **WHEN** the DJ opens Help › Tutorials › Looping and follows every step
- **THEN** they have set and saved a loop on a deck, and Looping is marked done
