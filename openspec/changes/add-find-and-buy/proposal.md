# Proposal

Planned for: **v0.5 · Buy it from the artist**

## Why

Seba has about 1,700 rated or played streamed tracks with no local copy, and Spotify playlists he'd like to own. Finding where to buy each track should be one action, artist-direct stores first.

## What Changes

- Find and buy for tracks without a file: from a Spotify playlist (browse only), the wanted list, or VirtualDJ entries without files.
- Search artist-direct stores first (Bandcamp, then others), then other stores, and show the best match per track.
- Store links point to the artist's own page first, then Beatport, Juno, Traxsource and Qobuz.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `library-sources`: Find and buy for tracks without a local file

## Out of Scope

- Streaming playback.
- Automatic purchasing.

## Impact

app stores.rs, Spotify browse (sign-in with the DJ's own client ID), library wanted list.
