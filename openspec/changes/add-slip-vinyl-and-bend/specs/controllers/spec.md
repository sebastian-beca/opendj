## ADDED Requirements

### Requirement: Vinyl mode
Each deck SHALL have `vinyl_mode`, on by default and set for every deck by Settings › Decks › Vinyl mode (the decks show no VINYL button). The DDJ-FLX4 and DDJ-FLX6 mappings SHALL scratch when the jog's top is touched only while it is on; while it is off, turning the top SHALL bend like the rim.

#### Scenario: CDJ mode
- **WHEN** Vinyl mode is off and the DJ touches and turns the top of a playing deck's jog
- **THEN** the deck keeps playing, bent faster or slower
